## 1. Descripción de la versión

La versión 0.1.0 de AlmaGest representa el primer
punto de referencia documental del proyecto.

Esta versión consolida la planificación inicial,
los requisitos del sistema, el modelado UML,
la arquitectura propuesta y el seguimiento
de las actividades mediante GitHub.

No constituye una versión ejecutable del software.

## 5. Limitaciones conocidas

Esta versión presenta las siguientes limitaciones:

1. No existe todavía una aplicación ejecutable.
2. El frontend y backend están definidos
   conceptualmente, pero no implementados.
3. No se ha seleccionado definitivamente
   el conjunto de tecnologías.
4. La base de datos aún no ha sido implementada.
5. Los requisitos iniciales requieren validación
   con usuarios reales antes del desarrollo final.
6. No se han ejecutado pruebas funcionales
   sobre el software.

## 6. Riesgos principales

- Errores en el diseño de la base de datos.
- Inconsistencias en las cantidades del inventario.
- Retrasos durante la implementación.
- Acceso no autorizado a funciones del sistema.

Estos riesgos cuentan con acciones preventivas
documentadas durante la planificación del proyecto.
