
# Modelado UML – AlmaGest

## Objetivo

Documentar los modelos UML utilizados para representar
la estructura y el comportamiento del sistema AlmaGest.

## Diagrama de casos de uso

El diagrama de casos de uso identifica las principales
interacciones entre los usuarios y las funcionalidades
previstas del sistema.

### Actores

1. Encargado de almacén.
2. Supervisor.
3. Administrador.

### Casos de uso principales

- Iniciar sesión.
- Gestionar materiales.
- Registrar entradas.
- Registrar salidas.
- Consultar existencias.
- Consultar historial de movimientos.
- Generar reportes.
- Gestionar usuarios.
- Gestionar roles y permisos.

## Relación entre actores y funcionalidades

| Actor | Funcionalidades |
|---|---|
| Encargado de almacén | Gestionar materiales, registrar entradas y salidas, consultar existencias |
| Supervisor | Consultar existencias, historial y reportes |
| Administrador | Gestionar usuarios, roles y permisos |

Todos los actores deberán autenticarse para acceder
a las funciones autorizadas.
