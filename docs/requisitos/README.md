
# Requisitos del sistema AlmaGest

## Objetivo

Documentar las necesidades, historias de usuario y requisitos funcionales y no funcionales del sistema AlmaGest.

## Historias de usuario

- HU-01: Registrar movimientos de inventario.
- HU-02: Consultar existencias de materiales.
- HU-03: Registrar entradas y salidas de materiales.
- HU-04: Consultar historial de movimientos.
- HU-05: Generar reportes de inventario.

## Requisitos funcionales

- RF-01: Registrar movimientos.
- RF-02: Consultar existencias.
- RF-03: Registrar entradas y salidas.
- RF-04: Consultar historial.
- RF-05: Generar reportes.

## Requisitos no funcionales

- RNF-01: Autenticación.
- RNF-02: Usabilidad.
- RNF-03: Rendimiento.

## Seguimiento

Las historias de usuario se encuentran documentadas en los Issues #8 al #12 del repositorio.
